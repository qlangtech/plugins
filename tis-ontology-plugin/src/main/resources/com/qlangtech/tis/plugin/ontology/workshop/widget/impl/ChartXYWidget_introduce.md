# Chart XY 组件简介

## 组件概述

Chart XY 是 TIS Workshop 中的图表组件，用于把本体（Ontology）中的对象数据画成柱状图、折线图或散点图。它面向的是"需要在一张图里观察多个维度数据"的构建者：数据来自当前模块中已有的对象集变量，用户不必写 SQL，也不必关心聚合与分组如何执行。

它与普通"一个组件一张图"的图表不同——一个 Chart XY 组件由若干**图层**叠加而成，因此同一张画布上可以同时呈现"告警数量"的柱子和"平均延误时长"的折线。

## 核心作用

- **多图层叠加**：每个图层是一份数据输入加一种画法。既可以组合来自不同对象集的图层，也可以在同一个对象集上做"柱 + 线"的组合图
- **服务端聚合**：分组、聚合、排序全部下推到数据库执行，只把聚合后的少量分组结果返回浏览器。即使底表有上亿行，图表依然响应迅速
- **共享坐标轴**：图层的数量不影响坐标轴的配置——轴的标题、刻度、网格线、数值格式化只配置一次，所有图层共用
- **自动图例**：图例由各图层内系列的配色与名称自动生成，构建者只需决定显不显示、放在哪里

## 适用场景

- 按类型、状态等分类维度统计对象数量（柱状图）
- 观察某个指标随时间的变化趋势（折线图，按天/小时等粒度分桶）
- 对比同一分类下不同子组的表现（按属性二次分段，支持并列、堆叠、百分比）
- 在同一个面板里同时看"量"与"率"这类量纲不同的指标（组合图）

## 工作机制

保存配置时会执行两项校验：

1. **轴性质校验**——X 轴必须是分类轴、Y 轴必须是连续轴。这是因为 X 上的取值来自服务端分桶后的离散标签，Y 上是聚合得到的数值；配反了不会报错，但会画出一张空白的图
2. **方向校验**——只有全部图层都是柱状图时才能选"横向"；只要有一层是折线或散点，整张图只能纵向。原因是一张图只有一对共享的坐标轴，横向柱与纵向折线对轴的要求互相矛盾

数据请求时，组件会按图层逐一取数：把每个图层翻译成"分组 + 聚合"的查询，交由对应的数据库执行，再把结果整理成前端可直接渲染的序列。图层上绑定的"选择即过滤"变量，会把用户在图表上的选择变成下游组件的过滤条件。

## 使用建议

- **先建变量，再配图表**：图层的数据源只能是当前模块中已存在的对象集变量，配置前请先确认变量已创建
- **不要把方向当成单个图层的属性**：方向属于整张图。若中途给横向柱图新增折线图层，保存时会被拦下，这是预期行为
- **注意分桶粒度**：同一属性切成"天"和"小时"是两张完全不同的图，桶数过多时请调低"桶数上限"
- **留意截断提示**：当分组数超过上限时返回结果会带截断标记，前端应显式提示，否则容易误以为"数据就这么点"
- **数据源方言**：目前只有 MySQL / MariaDB / TiDB / OceanBase / Doris / StarRocks 支持服务端聚合，其他数据源会直接报错而不会悄悄退回内存计算
